# RoadExp - Новый подход

Архитектура приложения RoadExp 3 разрабатывалась, в основном, с учетом принципов сформулированных в книге Robert C. Martin Clean Architecture. Однако, специфика предметной области, некоторые объективные и, конечно, субъективные факторы оказали своё влияние на построение архитектуры.

Архитектуру приложения условно можно разделить на три большие части (слоя), которые в свою очередь могут делиться на более мелкие части:
1. **Измерительные системы:** управление физическим устройством (передача настроек устройству), получение данных от физического устройства, сохранение полученных данных на диск
2. **Управление измерительными системами:** бизнес-логика приложения, взаимодействие систем, метрология, управление настройками систем и др.
3. **Пользовательский интерфейс:** консольное приложение, WPF, AvaloniaUI

Подробности в разделе Wiki (http://192.168.1.40/lab/roadexptest/-/wikis/home) и в исходном коде.
